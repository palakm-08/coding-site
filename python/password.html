Build a Random Password Generator in Python — Beginner Mini Project with Code

Python Beginner Mini Project Updated July 2026

Want to build a practical Python project in under 10 minutes? This beginner-friendly password generator teaches Python strings, loops, random numbers, and user input while creating secure random passwords. A random password generator is one of the best beginner projects — it's actually useful, covers real Python concepts, and you can extend it in a dozen directions. This guide walks through the full build, explains every line, and includes a strength checker upgrade.

Why Build a Password Generator?

  • Strong passwords are your first defense against brute force attacks — and coming up with random strings manually is a pain.
  • This project covers random, string, user input, loops, and conditionals — all core Python concepts in one go.
  • It's short enough to finish in one sitting but rich enough to extend into something genuinely useful.

How It Works — The Logic

Before touching the code, here's the idea in plain English:

01

Ask the user how long the password should be using input().

02

Build a pool of characters — letters, digits, and symbols — using Python's string module.

03

Pick characters randomly from the pool using random.choice(), repeating for the requested length.

04

Join the picked characters into one string using ''.join() and print the result.

Python Code — Console Password Generator

Python 
import random
import string

print("Welcome to Python Password Generator!")

length = int(input("Enter password length: "))

characters = string.ascii_letters + string.digits + string.punctuation

password = ''.join(random.choice(characters) for _ in range(length))

print("Your generated password is:", password)

Code Explanation — Line by Line

→

import string — gives access to string.ascii_letters (a–z + A–Z), string.digits (0–9), and string.punctuation (symbols like !@#$).

→

import random — used to randomly pick characters from the pool.

→

int(input(...)) — reads the desired password length from the user and converts it from a string to an integer.

→

characters = ... — builds the full character pool by combining all three string constants into one long string.

→

random.choice(characters) — picks one random character from the pool. This runs once per loop iteration.

→

''.join(...) — glues all the randomly selected characters together into one complete password string.

Upgrade — Add a Password Strength Checker

Once you've generated the password, it's worth checking how strong it actually is. This version adds a strength rating based on length and character variety:

Python 
import random
import string

length = int(input("Enter password length: "))
characters = string.ascii_letters + string.digits + string.punctuation
password = ''.join(random.choice(characters) for _ in range(length))

print("Generated password:", password)

# Strength checker
has_lower  = any(c.islower() for c in password)
has_upper  = any(c.isupper() for c in password)
has_digit  = any(c.isdigit() for c in password)
has_symbol = any(c in string.punctuation for c in password)

score = sum([has_lower, has_upper, has_digit, has_symbol])

if length >= 12 and score == 4:
    print("Strength: Strong")
elif length >= 8 and score >= 3:
    print("Strength: Moderate")
else:
    print("Strength: Weak")
What this adds

The checker uses four boolean checks — lowercase, uppercase, digits, symbols — and counts how many pass. Combined with a length check, it produces a Weak / Moderate / Strong rating. This is a simplified version of how real password validators work.

Things to Try Next

Let the user choose character types

Ask whether to include symbols or digits — some sites don't allow certain characters.

Generate multiple passwords at once

Add a second input asking how many passwords to generate, then loop and print each one.

Use secrets instead of random

For cryptographically secure passwords, swap random.choice() for secrets.choice() — same syntax, much stronger randomness.

Build a Tkinter GUI version

Add a simple window with a slider for length, a generate button, and a copy-to-clipboard feature.
