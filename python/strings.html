What Are String Methods? (Python Docs Explained)

A string method is a function that "belongs" to a string and is called with dot notation — my_string.method(). A string method never changes the original string. Depending on the method, it can return a new string, a Boolean, a number, a list, a tuple, or another object. That single fact explains almost every beginner surprise you'll run into with strings.

From the Python docs

Strings implement all of the common sequence operations, along with the additional methods described below.

String methods don't modify the original string because strings in Python are immutable. Depending on the method, they can return a new string, a number, a Boolean value, or another object — "hello".count("l") returns an int, split() returns a list, and partition() returns a tuple.
Never modify in placeA string method never edits the original — the original string is untouched
Case & Unicode awareMethods like casefold() and isalpha() understand more than plain ASCII
Chainables.strip().lower() runs left to right on each result
Consistent namingis* methods return True/False; the rest return strings, numbers, or lists
Strings never change in place. name.upper() does not modify name — it returns a new, uppercased string. If you want to keep the result, you have to assign it: name = name.upper().

Changing Case — capitalize(), casefold(), lower(), upper(), swapcase(), title()

Six methods for converting a string's case. They look similar but behave differently in ways that matter once you're dealing with more than plain English text.

PythonPython docs examples
# lower() — straightforward lowercasing
'Lower Method Example'.lower()
# 'lower method example'

# casefold() is more aggressive than lower() — built for caseless matching
'straße'.lower()
# 'straße'   ← unchanged, ß has no simple lowercase form
'straße'.casefold()
# 'strasse'  ← casefold() expands ß to 'ss'

# swapcase() — flips every character's case
'Hello World'.swapcase()
# 'hELLO wORLD'

# title() — capitalizes the first letter of every word
'Hello world'.title()
# 'Hello World'

Kiddo extra — capitalize() and upper()

PythonKiddo example
player = "mbappe"
print(player.capitalize())   # Mbappe — only the first letter is capitalized
print(player.upper())        # MBAPPE — every letter uppercased

shout = "GOOOOAL"
print(shout.capitalize())    # Goooooal — capitalize() lowercases the rest too
title() has a well-known apostrophe quirk — from the Python docs: "they're bill's friends".title() gives "They'Re Bill'S Friends", not "They're Bill's Friends". The algorithm treats an apostrophe as a word boundary, so the letter right after it gets capitalized too.

s.lower()All characters to lowercase'PYTHON'.lower() → 'python'

Checking String Content — the is* Methods

These twelve methods all answer a yes/no question about what's inside a string, and every one of them returns True or False. They're the backbone of input validation — checking whether something looks like a number, a valid variable name, or plain whitespace before you act on it.

PythonPython docs examples
# isalnum() — letters AND numbers, no punctuation or spaces
'abc123'.isalnum()       # True
'abc123!@#'.isalnum()    # False

# isalpha() — letters only
'LettersOnly'.isalpha()  # True
'Letters and spaces'.isalpha()  # False — spaces aren't letters

# isascii() — every character fits in basic ASCII
'ASCII characters'.isascii()  # True
'µ'.isascii()              # False

# islower() / isupper()
'banana'.islower()       # True
'BANANA'.isupper()       # True
'baNana'.isupper()       # False — mixed case

# istitle()
'Spam, Spam, Spam'.istitle()  # True
'spam, spam, spam'.istitle()  # False

# isspace()
' '.isspace()              # True
'\t\n'.isspace()          # True
''.isspace()               # False — needs at least one character

# isprintable()
' '.isprintable()          # True
'\n'.isprintable()         # False — a newline isn't "printable"

# isidentifier() — would this be a legal variable name?
'hello'.isidentifier()     # True
'def'.isidentifier()       # True — looks valid, even though it's a reserved keyword
isdecimal() vs isdigit() vs isnumeric() — from the Python docs: these three overlap but aren't identical. '²'.isdecimal() is False, but '²'.isdigit() and '²'.isnumeric() are both True — a superscript "2" isn't a plain decimal digit, but it does count as a digit and a numeric character. For everyday validation of typed-in numbers, isdecimal() is usually what you want.
MethodReturns True when the string is…
s.isalnum()Made only of letters and/or numbers, and non-empty
s.isalpha()Made only of letters, and non-empty
s.isascii()Empty, or every character fits in ASCII (U+0000–U+007F)
s.isdecimal()Made only of base-10 decimal digits, and non-empty
s.isdigit()Made only of digit characters (a superset of decimal), and non-empty
s.isnumeric()Made only of numeric characters, including fractions like ⅕
s.islower()All cased characters are lowercase, with at least one cased character
s.isupper()All cased characters are uppercase, with at least one cased character
s.istitle()Title-cased — each word starts uppercase, rest lowercase
s.isspace()Made only of whitespace characters, and non-empty
s.isprintable()Empty, or contains no non-printable characters (like \n or \t)
s.isidentifier()Syntactically valid as a Python variable/identifier name

Finding & Counting Text — count(), find(), rfind(), index(), rindex()

Five methods for locating a substring inside a string, or counting how often it shows up. The key distinction to remember: find() and index() do the same job, but they disagree on what happens when nothing is found.

PythonPython docs examples
# count() — how many times does 'spam' appear?
'spam, spam, spam'.count('spam')          # 3
'spam, spam, spam'.count('spam', 5)       # 2 — start searching from index 5

# find() — returns the lowest index, or -1 if not found
'spam, spam, spam'.find('sp')            # 0
'spam, spam, spam'.find('sp', 5)         # 6

# index() — same as find(), but raises ValueError instead of returning -1
'spam, spam, spam'.index('spam')         # 0
'spam, spam, spam'.index('eggs')
# ValueError: substring not found

# rfind() / rindex() — search from the right instead
'spam, spam, spam'.rfind('sp')           # 12 — the last match
'spam, spam, spam'.rindex('spam')         # 12
From the Python docs: the find() method should be used only if you need to know the position of a substring. To simply check whether one string contains another, use the in operator instead: 'Py' in 'Python' → True. It's clearer to read and doesn't tempt you to compare a return value to -1.
MethodWhat it doesIf not found
s.count(sub)Counts non-overlapping occurrences of subReturns 0
s.find(sub)Lowest index where sub startsReturns -1
s.rfind(sub)Highest index where sub startsReturns -1
s.index(sub)Lowest index where sub startsRaises ValueError
s.rindex(sub)Highest index where sub startsRaises ValueError

Checking Prefixes & Suffixes — startswith(), endswith()

Two methods for checking how a string begins or ends — cleaner and safer than slicing the string yourself and comparing it manually. Both accept a tuple of options, so you can check for several prefixes or suffixes in one call.

PythonPython docs examples
# startswith()
'Python'.startswith('Py')                       # True
'a tuple of prefixes'.startswith(('at', 'a'))  # True — matches any item in the tuple
'Python is amazing'.startswith('is', 7)    # True — start checking from index 7

# endswith()
'Python'.endswith('on')                         # True
'a tuple of suffixes'.endswith(('at', 'es'))  # True
'Python is amazing'.endswith('is', 0, 9)  # True — only looks within s[0:9]

Kiddo extra — checking a file type by extension

PythonKiddo example
filename = "squad_photo.PNG"

if filename.lower().endswith((".png", ".jpg", ".jpeg")):
    print("Valid image file")
# Valid image file
# .lower() first makes the check case-insensitive — .PNG still matches
MethodWhat it does
s.startswith(prefix)True if s begins with prefix — prefix can be a tuple
s.endswith(suffix)True if s ends with suffix — suffix can be a tuple

Basic String Cleaning — strip(), lstrip(), rstrip()

Three methods for removing unwanted characters from the ends of a string — most often whitespace left over from user input. The name "strip" is a little misleading, and the Python docs are careful to explain exactly what it does.

PythonPython docs examples
# With no argument — strips whitespace from both ends
'   spacious   '.strip()     # 'spacious'
'   spacious   '.lstrip()    # 'spacious   '
'   spacious   '.rstrip()    # '   spacious'

# With a chars argument — removes any of those characters, in any order
'www.example.com'.strip('cmowz.')   # 'example'

# A real-world cleanup case, straight from the docs
comment_string = '#....... Section 3.2.1 Issue #32 .......'
comment_string.strip('.#! ')
# 'Section 3.2.1 Issue #32'
chars is a set of characters, not a prefix — from the Python docs: 'mississippi'.rstrip('ipz') gives 'mississ'. Python doesn't remove the literal string 'ipz' — it keeps stripping characters from the end as long as they're any of i, p, or z, in whatever order they appear. This is the single most common surprise with strip().
MethodWhat it does
s.strip(chars=None)Removes matching characters from both ends (whitespace by default)
s.lstrip(chars=None)Removes matching characters from the left end only
s.rstrip(chars=None)Removes matching characters from the right end only

Common String Method Mistakes

Forgetting that string methods return a new string

name.strip() on its own does nothing useful — the cleaned string is thrown away unless you store it: name = name.strip(). Strings can't be changed in place.

Treating strip()'s argument as a prefix or suffix

'Monty Python'.strip(' Python') gives 'M', not 'Monty' — every character in ' Python' gets stripped from both ends. Use removeprefix()/removesuffix() when you want to remove one exact string instead.

Using find() and checking against 0 for "not found"

find() returns -1 when nothing is found, not 0 — a match at the very start of the string legitimately returns 0. Check if s.find(sub) != -1:, or better, just use if sub in s:.

Assuming isdigit() and isdecimal() always agree

Superscript digits, Roman numerals, and fraction characters can make isdigit() or isnumeric() return True while isdecimal() returns False. For validating plain typed-in numbers, isdecimal() is the safest choice.

Expecting title() to handle apostrophes gracefully

"bill's".title() gives "Bill'S", capitalizing the letter right after the apostrophe. It's a known quirk of the simple word-boundary rule title() uses.

Forgetting startswith()/endswith() are case-sensitive

"Python".startswith("py") is False — the cases must match exactly. Call .lower() on both sides first if the check should ignore case.

Python String Method Interview Questions and Answers

Q1 Why don't string methods modify the original string?
Strings are immutable in Python — once created, a string object's contents can never change. Every string method returns a brand-new string with the result, leaving the original untouched. That's why s.upper() alone has no visible effect unless you assign the result back to a variable.
Q2 What is the difference between find() and index()?
Both return the lowest index where a substring starts. The difference is what happens on failure: find() returns -1, while index() raises a ValueError. Use find() when "not found" is a normal case you'll handle; use index() when not finding it should be treated as an error.
Q3 What does strip() actually remove?
By default, whitespace from both ends. When given a chars argument, it removes any character that appears in that argument — treating it as a set of characters, not a literal prefix or suffix — until it hits a character not in the set.
Q4 How would you check if a string contains only digits typed by a user?
s.isdecimal() is the most appropriate check for typed input, since it's limited to base-10 digit characters. isdigit() and isnumeric() are broader and would also accept characters like superscripts or fractions that int() can't actually convert.
Q5 What's the difference between lower() and casefold()?
lower() does simple lowercasing. casefold() is more aggressive and is specifically designed for caseless string comparison — it can change a character's length, like turning the German ß into ss, which lower() leaves untouched.
Q6 How do startswith() and endswith() accept multiple options at once?
Both accept a tuple instead of a single string: s.startswith(('Mr.', 'Mrs.', 'Dr.')) returns True if the string starts with any item in the tuple. This avoids writing several separate or-chained checks.

Mini Project — Build a Player Signup Cleaner Using String Methods

A classic real-world use case for string methods — cleaning up messy, inconsistent user input before it gets stored anywhere. Signup forms are never typed perfectly, and this project uses every category from this page to fix that.

Clean the whitespace

Use strip() on every field first. Stray leading/trailing spaces from copy-pasted input are the most common source of "why doesn't this match?" bugs.

Normalize the name's case

Run the player's name through title() so "kevin de bruyne" and "KEVIN DE BRUYNE" both become "Kevin De Bruyne" before saving.

Validate the username

Use isidentifier() as a Python-specific validation example. It accepts strings that follow Python's identifier rules and rejects names with spaces, leading digits, or invalid characters. For real usernames, use validation rules designed for your application's requirements.

Check the email domain

Use endswith() with a tuple of allowed domains to confirm the email looks legitimate before accepting the form.

Count repeated submissions

Use count() on a log of past usernames to flag anyone who has tried to sign up under a slightly different casing of the same name.

Level up: chain the methods together — name.strip().title() cleans and formats in a single line. Chaining is one of the most useful habits to build once you're comfortable with individual string methods.
