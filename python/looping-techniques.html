Python Looping Techniques Explained (Python Docs 5.6) | enumerate(), zip(), reversed(), sorted() & Beginner Guide

📖 Based on Python 3 official docs §5.6 — explained like a friend, with extra examples added
Python Beginner Loops Official Docs Updated July 2026

This page explains the official Python Looping Techniques documentation (Python Docs 5.6) in simple language. Python has a handful of built-in functions that make looping cleaner, more readable, and more Pythonic. Instead of tracking index variables manually or writing extra code, you can use enumerate(), zip(), reversed(), sorted(), and set() directly inside your loops.

By the end of this guide you'll know exactly when to reach for each one — and why they're better than the alternative.

Quick Overview — All 5 Techniques

The Python docs §5.6 covers five built-in functions that make looping cleaner. Here's the full picture before we dig into each one:

.items()
Loop a dictionary — get key and value together

No need to do d[key] inside the loop. .items() unpacks both at once.

enumerate()
Loop a sequence — get index and value together

Replaces the manual i = 0; i += 1 pattern entirely.

zip()
Loop two or more sequences in parallel

Pairs up elements by position — stops at the shortest.

reversed()
Loop a sequence in reverse order

Doesn't create a copy — uses an iterator. Works on any sequence.

sorted()
Loop a sequence in sorted order

Returns a new sorted list — leaves the original untouched.

items() — Looping Through Dictionaries

When looping through a dictionary, you normally only get the key. Using .items() gives you the key and its value at the same time — no need to look up d[key] inside the loop.

Python Python docs §5.6 
knights = {'gallahad': 'the pure', 'robin': 'the brave'}
for k, v in knights.items():
    print(k, v)

gallahad the pure
robin the brave

Kiddo extra — real-world use

Python Kiddo example 
scores = {'Palak': 92, 'Rohan': 78, 'Sneha': 85}

for name, score in scores.items():
    if score >= 90:
        print(f"{name} scored A grade!")
    else:
        print(f"{name}: {score}")

Palak scored A grade!
Rohan: 78
Sneha: 85

enumerate() — Get Index and Value Together

When looping through a sequence, you often need both the position and the value. The old way is a manual counter. enumerate() does it in one clean step.

Python Python docs §5.6 
for i, v in enumerate(['tic', 'tac', 'toe']):
    print(i, v)

0 tic
1 tac
2 toe

Kiddo extra — start= and real-world use

Python Kiddo example 
subjects = ['Python', 'DSA', 'DBMS', 'OS']

# Default: starts at 0
for i, subject in enumerate(subjects):
    print(f"{i}. {subject}")
# 0. Python  1. DSA  2. DBMS  3. OS

# start=1 — human-friendly numbering
for i, subject in enumerate(subjects, 1):
    print(f"{i}. {subject}")
1. Python
2. DSA
3. DBMS
4. OS
Why not just use range(len(list))? for i in range(len(subjects)) works but forces you to write subjects[i] everywhere. enumerate() gives you both directly — cleaner, less error-prone, and the officially recommended pattern.

zip() — Loop Two Sequences in Parallel

When you have two lists that go together — questions and answers, names and scores, keys and values — zip() pairs them up by position so you can loop both at once.

Python Python docs §5.6 
questions = ['name', 'quest', 'favorite color']
answers   = ['lancelot', 'the holy grail', 'blue']

for q, a in zip(questions, answers):
    print('What is your {0}?  It is {1}.'.format(q, a))

What is your name?  It is lancelot.
What is your quest?  It is the holy grail.
What is your favorite color?  It is blue.

Kiddo extra — practical patterns

Python Kiddo example 
names  = ['Palak', 'Rohan', 'Sneha']
scores = [92, 78, 85]
grades = ['A', 'C', 'B']

# zip() works on 3+ sequences too
for name, score, grade in zip(names, scores, grades):
    print(f"{name}: {score} (Grade {grade})")
Palak: 92 (Grade A)
Rohan: 78 (Grade C)
Sneha: 85 (Grade B)

# zip stops at the shortest sequence
list(zip([1,2,3], ['a','b']))
[(1, 'a'), (2, 'b')]  # 3 is dropped

reversed() — Loop a Sequence Backwards

To loop in reverse, pass your sequence to reversed(). It returns an iterator — no copy is made, so it's memory efficient. Works on any sequence.

Python Python docs §5.6 
for i in reversed(range(1, 10, 2)):
    print(i)

9
7
5
3
1

Kiddo extra — reversed() on a list

Python Kiddo example 
steps = ['Import data', 'Clean data', 'Analyse', 'Visualise']

print("Undo order:")
for step in reversed(steps):
    print(f"  ← {step}")
Undo order:
  ← Visualise
  ← Analyse
  ← Clean data
  ← Import data

# reversed() does NOT modify the original list
print(steps)  # still in original order

sorted() — Loop in Sorted Order

sorted() returns a new sorted list from any iterable, leaving the original untouched. It's the cleanest way to loop through data in alphabetical or numerical order.

Python Python docs §5.6 
basket = ['apple', 'orange', 'apple', 'pear', 'orange', 'banana']

for i in sorted(basket):
    print(i)

apple
apple
banana
orange
orange
pear

sorted() + set() — Loop Unique Elements in Order

The Python docs call this an idiomatic Python pattern — combining set() to remove duplicates with sorted() to get a clean, ordered loop over unique values.

Python Python docs §5.6 
basket = ['apple', 'orange', 'apple', 'pear', 'orange', 'banana']

for f in sorted(set(basket)):
    print(f)

apple
banana
orange
pear
From the Python docs

Using set() on a sequence eliminates duplicate elements. The use of sorted() in combination with set() over a sequence is an idiomatic way to loop over unique elements of the sequence in sorted order.

Filtering While Looping — Create a New List Instead

The docs give an important piece of advice here: it's tempting to modify a list while looping over it, but it's often simpler and safer to create a new list instead. The math.isnan() example is the perfect illustration — filtering out NaN values cleanly:

Python Python docs §5.6 
import math

raw_data = [56.2, float('NaN'), 51.7, 55.3, 52.5, float('NaN'), 47.8]
filtered_data = []

for value in raw_data:
    if not math.isnan(value):
        filtered_data.append(value)

filtered_data
[56.2, 51.7, 55.3, 52.5, 47.8]

This pattern — loop the original, build a new filtered list — avoids the RuntimeError you'd get from deleting items while iterating. The same pattern written as a list comprehension is even cleaner:

Python Kiddo example 
import math

raw_data = [56.2, float('NaN'), 51.7, 55.3, 52.5, float('NaN'), 47.8]

# Same result, one line — list comprehension version
filtered_data = [v for v in raw_data if not math.isnan(v)]
print(filtered_data)
[56.2, 51.7, 55.3, 52.5, 47.8]
Rule from the docs: don't modify a list while looping over it. Either build a new list (as shown above), or loop over list(original) — a copy — if you must modify in place.

Common Mistakes

Using range(len()) instead of enumerate()

for i in range(len(items)) is verbose and error-prone. for i, item in enumerate(items) is cleaner, safer, and the Python-recommended way.

Expecting zip() to handle unequal lengths

zip() stops at the shortest sequence — extra elements in longer sequences are silently dropped. Use itertools.zip_longest() if you need to handle all elements.

Modifying a list while iterating over it

Adding or removing items during for item in my_list raises RuntimeError or silently skips elements. Always build a new list or iterate over a copy: for item in list(my_list).

Confusing reversed() with .reverse()

reversed(seq) returns an iterator — original untouched. list.reverse() modifies the list in place and returns None. For looping use reversed(); for permanent reversal use .reverse().

Python Looping Techniques Interview Questions

Q1What does enumerate() do and why use it over range(len())?
enumerate(iterable) returns pairs of (index, value) as you loop. It's cleaner than for i in range(len(items)): items[i] because you get both index and value directly. It also works on any iterable — not just lists — and you can set a custom start: enumerate(items, 1).
Q2What does zip() do and what happens with unequal lengths?
zip(a, b) pairs elements from both sequences by position and returns an iterator of tuples. It stops at the shortest sequence — extra elements are dropped silently. Use itertools.zip_longest(a, b, fillvalue=None) if you need to process all elements even when lengths differ.
Q3What is the difference between reversed() and list.reverse()?
reversed(seq) returns a reverse iterator — it doesn't modify the original and works on any sequence. list.reverse() reverses the list in place and returns None. For looping in reverse order, use reversed(). For permanently reversing a list, use .reverse().
Q4How do you loop over unique sorted elements of a list?
for item in sorted(set(my_list)) — the Python docs call this an idiomatic pattern. set() removes duplicates, sorted() returns a new sorted list. Together they give you a clean loop over each unique value in alphabetical or numerical order.
Q5Why shouldn't you modify a list while looping over it?
Modifying a list during iteration can raise RuntimeError: list changed size during iteration or silently skip elements — Python's loop iterator tracks an internal index, and insertions/deletions shift that. The safe approach is to build a new list (or use a list comprehension), or iterate over a copy: for item in list(my_list).

Python Looping Techniques FAQ

enumerate(iterable) adds a counter to an iterable and returns it as an enumerate object. In a for loop: for i, v in enumerate(items) gives you the index and value at each step. You can set the starting number with enumerate(items, start=1).
zip(a, b) pairs up elements from two (or more) iterables by position and returns an iterator of tuples. Useful for looping two related lists together. Stops at the shortest input — use itertools.zip_longest() if you need to handle all items from the longer sequence.
Use dict.items(): for k, v in my_dict.items():. This unpacks each key-value pair directly into two variables so you never need to write my_dict[k] inside the loop.
Use reversed(sequence) in your for loop: for item in reversed(my_list). It returns an iterator so no copy is made. The original list is unchanged. You can also use sorted(..., reverse=True) to loop in descending sorted order.
for item in sorted(set(my_list)). The Python docs call this idiomatic — set() removes duplicates and sorted() returns them in order. It's cleaner than manually deduplicating with conditions inside the loop.
